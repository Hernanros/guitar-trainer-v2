# Quick 260909-01: Tuning-Aware Sonnet + Mobile Tuning Label Summary

One-liner: Sonnet SYSTEM_PROMPT now mandates canonical-tuning identification + emission with 6 named alt-tunings; TabNotation surfaces the chosen tuning above the tab grid whenever non-standard.

## What Shipped

Two-pronged fix for the Lenny/SRV incident documented in investigation `260908-sonnet-tuning-quality.md`:

### Server (`server/app/ai/breakdown.py`)

- Inserted a `TUNING (CRITICAL — DO NOT SKIP)` block between the existing bullet list and `CRITICAL RULES:` in `SYSTEM_PROMPT` (verbatim from investigation lines 63-84 — LOCKED design, no paraphrase).
- Block enumerates 6 well-known alt-tunings (Open E, Open D, Open G, DADGAD, Drop D, Drop C) with array notation and example songs.
- Mandates emission of `tab.tuning` reflecting the chosen tuning.
- Mandates a `"Tuning: <name>"` technique note when the tuning is non-standard, with the verbatim Open-E retune instructions ("Tune your A, D, and G strings UP by a whole step...").
- Includes the "prefer authentic over simplified translations" instruction and the labeling escape hatch for pedagogical simplifications.
- Sharpened `_TOOL_DEF` description: replaced `"standard tuning unless the song calls for otherwise"` with `"in the song's canonical tuning per the TUNING protocol in the system prompt"` — removes the redundant fallback nudge that was overriding the new prompt block.

### Mobile (`mobile/src/components/TabNotation.tsx`)

- Added `STANDARD_TUNING` constant `['E', 'A', 'D', 'G', 'B', 'e']` (matches server schema default).
- Added `KNOWN_TUNINGS` lookup mapping serialized tuning arrays (joined with `|`) to friendly display names — arrays match SYSTEM_PROMPT block exactly.
- Added `tuningDisplay(tuning)` helper returning `{friendly, raw}` for label composition.
- Added `isStandardTuning(tuning)` helper — defensive fallback returns `true` for null / undefined / non-length-6 arrays so no misleading label renders on malformed data.
- Rendered a `<Text>` label above the existing `<ScrollView>` inside `styles.wrapper` — renders only when `tab.tuning` differs from standard.
- Label format:
  - **Known tuning:** `Tuning: Open E — E B E G# B E` (grey prefix, accent-orange friendly name, grey raw-array suffix)
  - **Unknown tuning:** `Tuning: E B E G# B E` (grey prefix, accent-orange raw joined array)
- Added `Text` to the `react-native` import line (was previously not imported — file only used `ScrollView`, `StyleSheet`, `View`).
- Added `tuningLabel`, `tuningPrefix`, `tuningValue`, `tuningRaw` style keys to the existing `StyleSheet.create` block.
- **Untouched:** SVG rendering, `Measure` memoized component, layout constants (`STRING_SPACING`, `BEAT_WIDTH`, `LEFT_MARGIN`, `TOP_PADDING`, `STRINGS`), `styles.wrapper`, `styles.scrollContent`. Zero risk to existing chord-diagram calibration.
