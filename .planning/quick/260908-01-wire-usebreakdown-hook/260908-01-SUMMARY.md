# Quick 260908-01: Wire useBreakdown Hook Summary

**One-liner:** Wires mobile's missing GET /api/v1/songs/{id}/breakdown call via a new TanStack Query hook, replacing the Grace-B inert placeholder with FletcherLoader (pending), BreakdownErrorCard (error, HTTP-status parsed), and breakdown.data-sourced render (success).

## What Shipped

### mobile/src/api/breakdown.ts (new, 41 lines)

- Exports `useBreakdown(songId: number | null): UseQueryResult<Breakdown>`.
- Exports `type Breakdown = components['schemas']['Breakdown']` for consumer typing (mirrors todaySong.ts export style).
- `queryKey: ['breakdown', songId]` — matches design_context; userId injected via header, not key.
- `queryFn: () => apiFetch<Breakdown>(`/api/v1/songs/${songId}/breakdown`)`.
- `enabled: songId != null` — no fetch on missing/NaN route param.
- `staleTime: Infinity` — server caches forever per D-11; client mirror.
- `retry: 0` — 429 (cap) and 503 (Fletcher voice) must be user-driven retries only (T-quick-01).

### mobile/src/app/breakdown/[songId].tsx (rewired)

- Added imports: `useBreakdown` from `../../api/breakdown`, `FletcherLoader` from `../../components/FletcherLoader`.
- Called `const breakdown = useBreakdown(songId);` alongside existing `useTodaySong()`.
- Render precedence (top-to-bottom):
  1. `useTodaySong` isLoading -> ActivityIndicator spinner (unchanged).
  2. `useTodaySong` isError / no `today` -> `BreakdownErrorCard` (unchanged behavior; onRetry now invalidates today-song directly).
  3. `breakdown.isError` -> `BreakdownErrorCard` with `code` parsed from HTTP status in error message (`HTTP 429`/`BREAKDOWN_CAPPED` -> `BREAKDOWN_CAPPED`; `HTTP 503`/`FLETCHER_OUT` -> `FLETCHER_OUT`; else `null`). onRetry calls `breakdown.refetch()`.
  4. `breakdown.isPending` -> song header + `FletcherLoader` with the three UI-SPEC section 3 messages: `Fletcher is listening...` -> `Working out the fingering...` -> `Almost there...`.
  5. Success -> extracts `const bd = breakdown.data;`; `technique_notes` / `tab` / `chords` now source from `bd`, not `song.breakdown`.
- Replaced today-song invalidation useEffect trigger: `Boolean(today)` -> `Boolean(breakdown.data)` (correct signal for governor_calls decrement).
- Removed dead code:
  - `handleBreakdownError` helper.
  - `errorCode` + `errorResetsAt` state.
  - Grace-B placeholder branch (`Fletcher preparing this breakdown...`).
  - Orphaned style keys: `placeholder`, `placeholderText`, `placeholderSubtext`.
