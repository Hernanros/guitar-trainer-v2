## Critical Anti-Patterns (do NOT repeat these)

- **Non-optional Pydantic field with cross-slice population deferred.** 04-01 declared `TodaySongResponse.breakdown_quota: BreakdownQuota` (no default) but assigned population to Slice B. Broke 2 Phase 3 tests between commits. Prevention: any new non-optional field must be populated in the SAME plan that adds it, OR the field must have a default until the populating plan lands.
- **Cross-slice scope skips.** 04-01 Task 2 (line 259) asked Slice A to prep count_tokens/record_estimate in onboarding.py so Slice C could just decorate. Slice A skipped; Slice C had to bundle. Prevention: plan-checker should verify each cross-slice-referenced file is either in the source plan's `files_modified` AND completed, OR moved entirely to the consuming plan.
- **`db.commit()` inside `@governed` closing parent SAVEPOINT.** Slice C discovered `@governed`'s commit was closing the SAVEPOINT that `bootstrap_user` had opened for fail-open behavior. Fresh `AsyncSessionLocal()` per `_bounded_verify` call was the fix. Prevention: any decorator that commits MUST document that it opens a fresh session, or the pattern breaks nested SAVEPOINT semantics.
