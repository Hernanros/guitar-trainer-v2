## Route File Structure (Expo v57)

Verified against https://docs.expo.dev/versions/v57.0.0/router/ before writing:
- Nested dynamic routes use directory segments: `[songId]/` directory creates a route group
- `_layout.tsx` inside `[songId]/` provides a Stack scope for the drill sub-routes
- `drill/[drillIndex].tsx` resolves as `/breakdown/[songId]/drill/[drillIndex]`

The parent `[songId].tsx` continues to serve the breakdown list — it is NOT shadowed by the `[songId]/` directory in Expo Router v57 (co-located file + directory is valid).

**Version-specific quirk confirmed:** In Expo Router v57, a file `[songId].tsx` and directory `[songId]/` can coexist in the same parent directory. The file handles the route at depth 1 (`/breakdown/42`), the directory handles deeper routes (`/breakdown/42/drill/0`).
