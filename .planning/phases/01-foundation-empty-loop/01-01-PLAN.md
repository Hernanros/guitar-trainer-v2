## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile app → FastAPI | App fetches from public Railway URL / localhost; no auth; response treated as trusted data |
| FastAPI → Postgres | Internal Railway network; DATABASE_URL injected by Railway; not user-controlled |
| Developer machine → EAS | EAS CLI uses Expo account credentials; not in-scope for Phase 1 threat model |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | GET /api/v1/song-of-day (no auth) | accept | POC design: single-user, no PII, no private data served. Phase 2 adds user identity. |
| T-01-02 | Tampering | songs table write path | accept | No write endpoints exist in Phase 1. Only `SELECT LIMIT 1` is executed. SQLAlchemy parameterization handles any future user-controlled input. |
